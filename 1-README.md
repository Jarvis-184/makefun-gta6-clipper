# GTA 6 Clipper

This project clips a high-action moment (02:18.2-02:25.1) from the official GTA 6 Trailer 2, adding a hook in the first 3 seconds, and a pitch for make.fun at the end. The final video is a ~13-second clip (6.9s trailer moment + 6s pitch). The video was created using ffmpeg as defined in `make-clip.sh`. The final video is uploaded to YouTube, and the link will be added to `VIDEO.json`. Footage is property of Rockstar Games.
